# sem5_pp

Задачки:
1) Перегонялка файлика. Напишите программу принимающую на
вход два имени файлов и копирует содержимое первого файла
во второй.
2) Жадина. Напишите программу, находящую все файлы (кроме
себя) в своей домашней директории (папке в которой она
находится) и копирующую все содержимое этих файлов в
общий файл GREEDY.TXT в алфавитном порядке названия
найденных файлов. (Смотрит себе под ноги, находит все файлы
читает их по порядку и записывает (добавляет) все что
прочитала в файл GREEDY.TXT, создающийся там же)
